🔄 The For Loop (ICU)

The standard `for` loop requires three parts: Init, Condition, and Update. It is best used when the exact number of iterations is known upfront.

For Loop
// Init ; Condition ; Update
for (let i = 0; i < 10; i++) {
    console.log(i);
}

⏳ While & Do...While

`while` is for unknown iteration counts (checks condition before body). `do...while` guarantees the body runs AT LEAST ONCE before checking the condition.

At Least Once Guarantee
let n = 100;
do {
    console.log("This runs once!");
} while (n < 0); // Condition is false

⛔ Break & Continue

`break` completely exits the nearest enclosing loop. `continue` skips the rest of the current iteration and jumps to the next one.

Control Flow
for (let i = 0; i < 10; i++) {
    if (i === 5) break; // stops at 5
    if (i % 2 === 0) continue; // skips evens
    console.log(i); // 1, 3
}

🧮 Pre vs Post Increment

`++i` increments FIRST, then uses the new value. `i++` uses the OLD value first, then increments. In a loop's update slot, they act identically.

Expressions Trap
let a = 5;
let b = a++; // b = 5, a = 6

let c = 5;
let d = ++c; // d = 6, c = 6
Practical Application

Real World & Common Mistakes

🛠️ Real-World Use Case

API Polling & Retry Logic: A `while` loop is perfect for retrying flaky API connections until a success threshold or max-attempts limit is reached.

Practical Example
let attempts = 0;
let success = false;

while (!success && attempts < 3) {
    attempts++;
    success = pingServer();
    console.log(`Attempt ${attempts}`);
}

❌ Common Developer Mistake

Var Leakage & Infinite Loops: Using `var` inside a loop leaks it to the global scope. Using `continue` inside a `while` loop BEFORE the update step causes an infinite loop.

Common Mistake
let i = 0;
while (i < 5) {
    // MISTAKE: i++ never runs if i === 2. Infinite Loop!
    if (i === 2) continue; 
    
    console.log(i);
    i++;
}
Zero to Hero

Interview Preparation

Q1: Can you use `break` inside `.forEach()`?
No! `break` is a statement that only works inside loop constructs (for, while). `forEach` uses a callback function, so `break` would cause a SyntaxError. You must use a regular `for` or `for...of` loop if you need to exit early.
Q2: What is the output of `let a = 5; let b = a++; console.log(b);`?
Answer: 5. The post-increment operator (`a++`) returns the original value before performing the increment.
Q3: Why should we never use `for...in` on an Array?
`for...in` iterates over ALL enumerable properties of an object, returning their keys as strings. If you or a library adds properties to the Array prototype, `for...in` will iterate over those too! Always use `for...of` for Arrays.
