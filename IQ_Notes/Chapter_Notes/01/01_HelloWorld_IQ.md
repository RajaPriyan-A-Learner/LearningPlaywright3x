# 01_HelloWorld — Your First JavaScript Program

**File:** `01_HelloWorld.js`

## Overview

The classic "Hello, World!" program—the traditional first step in learning any programming language. Demonstrates how to execute code and see output in the console.

## Basic Output with console.log()

```javascript
console.log("Hello The Testing Academy!");
```

- `console.log()` prints text to the console
- Argument can be string, number, object, array, or any JavaScript value
- Output appears in the browser console, Node.js terminal, or IDE output panel

## Why This Matters

This simple program demonstrates:
- How to write a statement (instruction ending with `;`)
- How to call a built-in function (`console.log`)
- How to pass a string literal (text in quotes) to a function
- How to see program output

---

## Summary

**Key Takeaway:** `console.log()` is your primary tool for debugging and understanding what your code does. You'll use it countless times to verify values, trace execution, and troubleshoot issues.
