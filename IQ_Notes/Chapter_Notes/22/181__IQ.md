# 181_ — Single Inheritance and Base Page Modeling in JavaScript

**File:** `22_chapter_Inheritance/Single Inheritance/181_.js`

## Overview
This file introduces Single Inheritance in JavaScript using the `extends` keyword. It demonstrates how a child class (`LoginPage`) inherits methods and behavior from a parent class (`BasePage`), which is the architectural cornerstone of the Page Object Model (POM) in test automation frameworks like Playwright.

---

## Main Concept
Inheritance enables a class (derived/child class) to acquire properties and methods from another class (base/parent class).

### The `extends` Keyword
- When `class LoginPage extends BasePage` is defined, JavaScript sets up a prototype chain link connecting `LoginPage.prototype` to `BasePage.prototype`.
- Any instance of `LoginPage` automatically gains access to methods defined on `BasePage` (`open()`, `close()`) without duplicate code.

### Code Example

```javascript
class BasePage {
    constructor(pageName) {
        this.pageName = pageName;
    }

    open() {
        console.log("Opening the page ");
    }

    close() {
        console.log("Closing the page ");
    }
}

class LoginPage extends BasePage {
    // Inherits constructor, open(), and close() automatically
}

let page = new LoginPage();
page.open();  // "Opening the page "
page.close(); // "Closing the page "
```

### Key Points
- If a derived class does not define a constructor, the default constructor `constructor(...args) { super(...args); }` is supplied automatically by JavaScript.
- Code reuse: Common navigation, timeouts, and teardown logic belong in `BasePage` and are inherited across dozens of specific page objects.
- Single Inheritance: In JavaScript, a class can extend only one superclass (`class A extends B`).

---

## Common Mistakes
- **Assuming multiple inheritance exists:** JavaScript does not support `class Child extends ParentA, ParentB`. For multi-class reuse, mixins or composition must be used.
- **Forgetting that methods reside on the prototype:** `open()` is not copied to each instance; it is looked up dynamically up the prototype chain.

---

## Summary
**Key Takeaway:** The `extends` keyword establishes a single inheritance relationship, allowing child classes like `LoginPage` to seamlessly inherit and execute behaviors from `BasePage`.
