# 183_IQ1 — Method Overriding and Polymorphism in Test Fixtures

**File:** `22_chapter_Inheritance/Single Inheritance/183_IQ1.js`

## Overview
This file demonstrates **Method Overriding**, a form of runtime polymorphism in JavaScript OOP. It shows how a derived test class (`APITest`) redefines the `setup()` method originally declared in `BaseTest` to provide specialized initialization behavior.

---

## Main Concept
Method Overriding occurs when a child class provides its own implementation of a method that has the exact same name as a method in its parent class.

### How Prototype Resolution Works During Overriding
- When `test.setup()` is called on an instance of `APITest`, the JavaScript engine searches for `setup` on `APITest.prototype`.
- Since `setup` is found directly on `APITest.prototype`, execution stops immediately and the child's method runs.
- `BaseTest.prototype.setup` is shadowed (overridden) unless explicitly invoked with `super.setup()`.

### Code Example

```javascript
class BaseTest {
    setup() {
        console.log("Base: open browser");
    }
}

class APITest extends BaseTest {
    setup() {
        console.log("APITest: open browser");
    }
}

let test = new APITest();
test.setup(); // Outputs: "APITest: open browser"
```

### Key Points
- In UI vs API test frameworks, API tests do not need to open a heavy browser instance; overriding `setup()` allows `APITest` to tailor its fixture initialization (e.g. creating an API client token instead of launching Chromium).
- Method overriding enables polymorphic behavior: callers treat objects through a common contract while each subtype executes its specialized logic.

---

## Common Mistakes
- **Assuming the parent method runs automatically:** In JavaScript, defining a method with the same name completely shadows the parent method. If parent setup is also needed, you must call `super.setup()`.
- **Misspelling the method name:** If `APITest` defines `setUp()` (capital U), it won't override `setup()`, leading to subtle inheritance bugs.

---

## Summary
**Key Takeaway:** Method overriding enables derived classes to replace or customize parent behaviors, allowing specialized test classes to adapt generic framework methods to their specific execution requirements.
