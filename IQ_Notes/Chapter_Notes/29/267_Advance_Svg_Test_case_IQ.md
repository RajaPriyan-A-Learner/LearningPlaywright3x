# 267_Advance_Svg_Test_case — Interactive SVG Charts & Shape Widgets

## Overview
This specification explores advanced interactions with interactive SVG charting components and graphical vector widgets. It covers clicking vector shapes (circles and bars), asserting dynamic DOM output generated by SVG click listeners, interacting with accessible controls inside SVG chart wrappers, and parsing attributes like `data-quarter` and `height` from vector chart bars.

---

## Main Concept
Interactive data visualizations (D3.js, Chart.js, Recharts) render analytical dashboards using SVG primitives such as `<rect>`, `<circle>`, `<path>`, and `<g>` tags. These elements frequently feature bespoke attributes (e.g., `data-quarter`, `height`, `cx`, `cy`) and bound JavaScript event listeners. Automating charts requires:
1. Targeting vector elements via specific IDs, CSS classes, or data attributes.
2. Interacting directly with vector shapes using `.click()`.
3. Reading SVG geometric and data attributes via `.getAttribute('height')` to validate visualization accuracy.

### Code Example

```typescript
import { test, expect, type Locator } from '@playwright/test';

const URL = 'https://app.thetestingacademy.com/playwright/widgets/svg';

test.describe('SVG handling', () => {
    test.beforeEach(async ({ page }) => {
        await page.goto(URL);
    });

    test('locate SVG root and assert visible', async ({ page }) => {
        const circleShape: Locator = page.locator('#circle-blue');
        await circleShape.click();

        const output = await page.locator('#shapes-output').innerText();
        expect(output).toContain('Blue circle');

        await page.getByRole('button', { name: /Q3 bar/ }).click();
        await page.getByRole('radio', { name: '4 stars' }).click();

        let allBars = await page.locator(".bar").all();
        for (const bar of allBars) {
            const q = await bar.getAttribute('data-quarter');
            const h = await bar.getAttribute('height');
            console.log(q);
            console.log(h);
        }
    });
});
```

**Why this approach was chosen:**
The coder chose to demonstrate that Playwright does not treat SVG graphics as non-interactive canvas pixels; instead, Playwright allows direct clicks, mouse hovering, attribute inspection, and DOM assertion across vector charts. Using `page.locator(".bar").all()` allows looping through SVG `<rect>` elements easily to read their visual metrics.

**Alternative Effective Ways:**
Instead of extracting the text with `innerText()` and running a non-retrying Jest-style assertion `expect(output).toContain(...)`, an alternative effective way is to use Playwright's web-first retrying assertion:
```typescript
await expect(page.locator('#shapes-output')).toContainText('Blue circle');
```
Web-first assertions automatically retry until the state change updates in the DOM, preventing race condition flakes if the SVG click listener operates asynchronously. Furthermore, for validating chart heights and values, you can assert attributes directly:
```typescript
await expect(page.locator('.bar[data-quarter="Q3"]')).toHaveAttribute('height', '180');
```

### Key Points
- SVG nodes (`<circle>`, `<rect>`, `<path>`) fire standard mouse events (`click`, `hover`, `mousemove`).
- Use web-first assertions (`await expect(locator).toHaveAttribute(...)`) to validate SVG visual attributes like `height`, `width`, `fill`, and `d`.
- Locators inside `<svg>` can be scoped using standard CSS hierarchies (`page.locator('svg .bar')`).

---

## Common Mistakes
- Relying on non-retrying assertions (`const val = await loc.innerText(); expect(val)...`) after clicking SVG elements that trigger asynchronous renders.
- Attempting to use `textContent()` on `<circle>` or `<rect>` elements; vector shapes do not hold textual content, only geometric attributes.
- Failing to account for CSS transforms or animations that may delay clickability.

---

## Summary
**Key Takeaway:** Testing SVG dashboards in Playwright is identical to standard HTML automation—vector shapes support direct clicks, attribute assertions, and web-first state validations.
