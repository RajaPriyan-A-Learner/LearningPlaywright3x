# 179_IQ3 — Config Encapsulation with Default Parameters in Environment Class

**File:** `21_chapter_Encapsulation/179_IQ3.js`

## Overview
This file demonstrates how classes can encapsulate environment configuration in automation frameworks. It leverages ES6 default parameter values in constructors alongside getter-like helper methods (`getURL()`) to generate target endpoints dynamically.

---

## Main Concept
Managing test environments (staging, production, QA, dev) is a primary responsibility in test automation frameworks like Playwright.

### Encapsulating Environment Configuration
- The constructor accepts `name` and `port` with sensible fallback defaults (`staging`, `3000`).
- `getURL()` computes the fully qualified URL dynamically from the encapsulated properties.

### Code Example

```javascript
class Environment {
  constructor(name = "staging", port = 3000) {
    this.name = name;
    this.port = port;
  }

  getURL() {
    return "http://" + this.name + ":" + this.port;
  }
}

let env1 = new Environment();
let env2 = new Environment("production", 8080);

console.log(env1.getURL()); // "http://staging:3000"
console.log(env2.getURL()); // "http://production:8080"
```

### Key Points
- Default constructor parameters (`name = "staging"`, `port = 3000`) provide a fail-safe fallback when arguments are omitted.
- `getURL()` provides a single source of truth for constructing endpoint URLs.
- In test automation suites, this pattern prevents hardcoded URLs across test files and enables clean multi-environment test execution.

---

## Common Mistakes
- **Passing `null` expecting default value:** Default parameters only trigger for `undefined` or omitted arguments, not for `null`. `new Environment(null, null)` sets `name = null` and `port = null`.
- **Hardcoding protocols or paths:** In advanced frameworks, protocols (`http`/`https`) and base paths should also be configurable or parameterized within the class.

---

## Summary
**Key Takeaway:** The `Environment` class encapsulates configuration settings with default parameters, providing clean, centralized, and dynamic endpoint generation for test automation frameworks.
