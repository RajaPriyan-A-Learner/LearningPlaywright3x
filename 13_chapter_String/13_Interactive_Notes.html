Core Concepts Extracted

📝 String Immutability

Primitive strings in JavaScript are immutable. Methods like `.replace()` or `.toUpperCase()` do not modify the original string; they return a completely new string.

Immutability
let text = "hello";
text.toUpperCase();
console.log(text); // Still "hello"!

// Must reassign
text = text.toUpperCase();

✨ Template Literals

String interpolation using backticks allows for embedded expressions and multi-line strings without needing manual concatenation or escape characters.

Backticks
let name = "Pramod";
let msg = `Welcome back, 
${name}! Have a good day.`;
console.log(msg);

🔍 Modern Searching

Checking contents of strings has been heavily modernized. Use `.includes()`, `.startsWith()`, and `.endsWith()` instead of `.indexOf() > -1`.

Modern Search
let url = "https://app.com";
url.startsWith("https"); // true
url.includes("app"); // true

✂️ Substrings

You can extract parts of strings using `.slice(start, end)` or `.substring(start, end)`. `.slice()` is generally preferred as it supports negative indices.

Extraction
let str = "Javascript";
console.log(str.slice(0, 4)); // "Java"
console.log(str.slice(-6));   // "script"
Practical Application

Real World & Common Mistakes

🛠️ Real-World Use Case

Parsing URLs & DOM Data: Strings are used extensively to parse query parameters, validate emails before submitting forms, and sanitize user input data (e.g. `.trim()`).

Practical Example
let userInput = "   John.Doe@gmail.com   ";

// Sanitization Pipeline
let cleanEmail = userInput.trim().toLowerCase();

if (!cleanEmail.includes("@")) {
    alert("Invalid email!");
}

❌ Common Developer Mistake

Using indexOf() in Boolean Checks: `.indexOf()` returns `0` if the match is at the very start of the string. But `0` is a falsy value in Javascript!

Common Mistake
let url = "http://api.com";

// MISTAKE: Returns 0, which evaluates to false!
if (url.indexOf("http")) {
    console.log("Secure"); // NEVER RUNS 💥
}

// CORRECT:
if (url.includes("http")) { ... }
Zero to Hero

Interview Preparation

Q1: How do you reverse a string in JavaScript?
There is no built-in `.reverse()` method for strings. You must split it into an array, reverse the array, and join it back:
str.split('').reverse().join('')
Q2: What is the difference between `slice()` and `substring()`?
Both extract parts of a string. `slice()` accepts negative indices (which count from the end of the string). `substring()` treats negative indices as `0`.
Q3: How do you get the last character of a string?
The old way is str[str.length - 1]. The modern, preferred ES2022 way is str.at(-1).
