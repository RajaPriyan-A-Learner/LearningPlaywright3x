🔀 The Switch Block

Evaluates an expression, matching the expression's value against a series of case clauses.

let day = 2;
switch(day) {
    case 1: console.log("Mon"); break;
    case 2: console.log("Tue"); break;
    default: console.log("Unknown");
}

🛑 The 'break' Keyword

If you forget the `break` keyword, execution "falls through" to the next case automatically, executing its code as well!

Interview Q&A

Q1: Does Switch use strict equality?
Yes! Switch uses strict equality (===) for comparison. The type and the value must match exactly. case "2": will not match a numeric 2.
