📏 Identifier Rules

Variables must start with a letter, underscore (_), or dollar sign ($). They cannot start with a number.

let _privateVar = 10;
let $element = "div";
let camelCase = true;

💼 Naming Conventions

JavaScript strictly uses `camelCase` for standard variables and `PascalCase` for Classes/Constructors.

Interview Q&A

Q1: Can we use Reserved Keywords as identifiers?
No! Keywords like `class`, `function`, or `const` cannot be used as variable names. However, they are case-sensitive, so technically `Function` is valid (though terrible practice!).
