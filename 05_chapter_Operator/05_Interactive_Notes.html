⚖️ Strict vs Loose Comparison

Always prefer strict equality (===) over loose (==) to avoid unexpected type coercion.

console.log(5 == "5");  // true
console.log(5 === "5"); // false

🎭 Ternary Operator

A shorthand for if-else statements. Perfect for conditional assignments.

let result = (age > 18) ? "Pass" : "Fail";
