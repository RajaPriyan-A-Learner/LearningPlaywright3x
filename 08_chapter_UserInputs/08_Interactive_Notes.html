Receiving data at runtime. Explore browser Prompts and Node.js command-line interfaces like Readline.

Deep Insights

Core Concepts Extracted

🌐 Browser prompt()

A synchronous browser API that displays a modal dialog. It returns a String if OK is clicked, or `null` if Cancel is clicked. NOT available in Node.js.

Browser Input
let age = prompt("Enter your age:");
if (age === null) {
    console.log("User cancelled!");
}

🖥️ Node.js readline (Async)

The built-in Node module for reading streams. It is fully asynchronous. You must call `rl.close()` or the Node process will hang forever.

Node Core Input
const rl = readline.createInterface({
    input: process.stdin, 
    output: process.stdout
});
rl.question("Name? ", (answer) => {
    console.log(answer);
    rl.close(); // Mandatory!
});

🛑 prompt-sync (Synchronous)

A popular third-party npm package used to mimic the browser's `prompt()` function in Node.js. It blocks the event loop until input is provided.

NPM Package
// npm install prompt-sync
const prompt = require("prompt-sync")();

// Execution completely stops here
let name = prompt("Name: ");

⚠️ The Type Coercion Rule

ALL user input methods return Strings. If you try to add numbers without explicit conversion, JavaScript will concatenate them instead.

Coercion Trap
let input = "42";
console.log(input + 5); // "425" 💥

let num = Number(input);
console.log(num + 5); // 47 ✅
Practical Application

Real World & Common Mistakes

🛠️ Real-World Use Case

CLI Automation Tools: In QA or DevOps, scripts often need to ask for a deployment environment or a one-time password before proceeding. `readline/promises` is perfect for this.

Practical Example
const { createInterface } = require("readline/promises");
const rl = createInterface({ input: process.stdin, output: process.stdout });

async function deploy() {
    const env = await rl.question("Deploy to DEV or PROD? ");
    console.log(`Deploying to ${env}...`);
    rl.close();
}

❌ Common Developer Mistake

Misunderstanding Async Execution Order: `readline.question` is asynchronous. Code written below it will run BEFORE the user even types anything!

Common Mistake
rl.question("Enter name: ", (input) => {
    console.log("B:", input); // Runs SECOND
    rl.close();
});

// MISTAKE: This runs FIRST, before user types!
console.log("A");
Zero to Hero

Interview Preparation

Q1: Can I use `prompt()` inside a Node.js script?
No. `prompt()` is part of the Window interface, which only exists in the browser DOM. Running it in Node.js will result in a `ReferenceError`. You must use `readline` or a package like `prompt-sync`.
Q2: What happens if you forget to call `rl.close()`?
The Node.js process will hang indefinitely. `readline` keeps the `process.stdin` stream open, waiting for more input. Closing it explicitly tells the Event Loop it can cleanly exit.
Q3: How do you safely convert string input to numbers?
Use `Number(input)` to convert the entire string (returns NaN if there's any invalid character), or `parseInt(input, 10)` to extract numbers from a mixed string (like `"42px"`).
