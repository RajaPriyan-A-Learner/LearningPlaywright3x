Mastering Arrays

JavaScript's primary ordered collection type — zero-indexed, dynamically-sized, and capable of holding mixed types.

Core Concepts Extracted

📦 Creating Arrays

The array literal is preferred. Avoid `new Array(n)` unless you specifically want a sparse array with empty holes (not `undefined`!).

Creation Methods
let arr = ["chrome", "firefox"]; // Best

let sparse = new Array(3); // [ <3 empty items> ]
let single = Array.of(3);  // [ 3 ]
let chars = Array.from("hi"); // ["h", "i"]

🔍 Searching & Indexing

`.indexOf()` is for finding the exact position, while `.find()` is for predicate functions. ES2022 gave us `.at()` for negative indexing!

Search & Access
let res = ["pass", "fail", "error"];

res.at(-1); // "error" (last element)
res.includes("fail"); // true
res.findIndex(s => s.startsWith("e")); // 2

🔄 Adding & Removing

`push/pop` operate on the END of the array. `unshift/shift` operate on the START. `splice` handles the MIDDLE.

Mutation
let q = [1, 2, 3];
q.push(4);    // [1, 2, 3, 4]
q.shift();    // [2, 3, 4]

// Splice: start 1, delete 1, insert 99
q.splice(1, 1, 99); // [2, 99, 4]

✨ ES2023 Non-Mutating Methods

Old methods like `.sort()` and `.reverse()` mutated the original array. Modern ES2023 introduced non-mutating alternatives that return a fresh copy.

Immutability
let nums = [3, 1, 2];

// Returns NEW array, leaves nums alone
let sorted = nums.toSorted((a,b) => a - b);
let rev = nums.toReversed();

Real World & Common Mistakes

🛠️ Real-World Use Case

Managing UI State & Data Tables: Arrays are the absolute backbone of rendering lists in frameworks like React. You constantly use `.map()` to render components and `.filter()` to implement Search Bars.

Practical Example
const activeUsers = users.filter(u => u.isActive);

activeUsers.forEach(user => {
    // Render user card to the DOM...
    console.log("Rendering: ", user.name);
});

❌ Common Developer Mistake

The `sort()` lexicographic trap: By default, JavaScript `.sort()` converts all values to strings before comparing them. This breaks numeric sorting!

Common Mistake
let scores = [10, 9, 2, 1, 100];

// MISTAKE: Sorts as strings!
scores.sort(); 
console.log(scores); // [1, 10, 100, 2, 9] 💥

// CORRECT: Use a comparator
scores.sort((a, b) => a - b); // [1, 2, 9, 10, 100] ✅
Zero to Hero

Interview Preparation

Q1: What is the output?
let arr = ["a", "b", "c"];
console.log(arr[-1]);
console.log(arr.at(-1));
Answer: `undefined` then `"c"`. `arr[-1]` looks for a literal property with the key `"-1"` (which doesn't exist). `arr.at(-1)` is the correct ES2022 method to get the last element.
Q2: How do you safely check if a value is an array?
Always use `Array.isArray(value)`. Do not use `typeof` (it returns "object") and be careful with `instanceof Array` (it fails across iframes).
Q3: What is the difference between `forEach` and `map`?
`forEach` iterates for side effects and always returns `undefined`. `map` transforms the array and returns a brand new array of the same length. Never use `map` if you don't intend to use the returned array!
