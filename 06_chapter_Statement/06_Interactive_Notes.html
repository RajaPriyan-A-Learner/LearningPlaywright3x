🔀 If / Else Statement

Executes a block of code if a specified condition is true. If false, another block of code can be executed.

let age = 16;
if (age > 18) {
    console.log("Go Goa");
} else {
    console.log("Not Goa");
}

🪜 Else-If Ladder

Useful for checking multiple separate conditions sequentially, like assigning grading scores.

Interview Q&A

Q1: Can an `else` statement exist without an `if`?
No, an `else` block must strictly follow an `if` or `else if` block. It acts as the default fallback when all preceding conditions evaluate to false.
