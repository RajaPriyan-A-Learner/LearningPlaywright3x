Core Concepts Extracted

📦 Creating 2D Arrays

An array containing other arrays. Used for grids, matrices, or tabular data.

Declaration
let matrix = [
    [1, 2, 3], // Row 0
    [4, 5, 6], // Row 1
    [7, 8, 9]  // Row 2
];
console.log(matrix[1][2]); // Prints 6 (Row 1, Col 2)

🔄 Iterating Nested Arrays

Using nested loops to access every element. The inner loop completes all its iterations for every single iteration of the outer loop.

For..of Traversal
for(let row of matrix) {
    for(let cell of row) {
        process.stdout.write(cell + " ");
    }
    console.log();
}

⚠️ The Array Fill Reference Trap

If you initialize a 2D array using `.fill([])`, it passes the exact same array memory reference to every row. Modifying one row modifies all rows!

Gotcha Fix
// BAD ❌
let badGrid = new Array(3).fill([0, 0, 0]);
badGrid[0][0] = 99; // Changes [1][0] & [2][0] too!

// GOOD ✅
let goodGrid = Array.from({length: 3}, () => [0, 0, 0]);

🚀 Built-in Flattening

Creates a new 1-dimensional array with all sub-array elements concatenated into it recursively up to the specified depth.

Array.flat()
let grid = [[1, 2], [3, 4]];
let flat = grid.flat(1);
console.log(flat); // [1, 2, 3, 4]
Practical Application

Real World & Common Mistakes

🛠️ Real-World Use Case

Grid-Based Games & UI Layouts: 2D Arrays are extensively used to model X/Y coordinates in logic. For example, a Tic-Tac-Toe board or a seating chart for an event app.

Practical Example
let board = [
    ["X", null, "O"],
    [null, "X", null],
    ["O", null, "X"]
];
if (board[0][0] === "X" && board[1][1] === "X" && board[2][2] === "X") {
    console.log("Player X wins the diagonal!");
}

❌ Common Developer Mistake

The `.fill()` Reference Trap: If you initialize an empty 2D grid using `.fill([])`, it passes the exact same array memory reference to every row. Modifying one row modifies them all!

Common Mistake
// MISTAKE: All rows point to the exact same array
let badGrid = new Array(3).fill([0, 0, 0]);
badGrid[0][0] = 99; // Changes [1][0] & [2][0] too! 💥

// CORRECT: Use Array.from() to map brand new arrays
let goodGrid = Array.from({length: 3}, () => [0, 0, 0]);

Interview Preparation

Q1: How do you transpose a 2D matrix (turn rows into columns)?
Using `.map()` along with the column index mapping the rows.

let transposed = matrix[0].map((_, colIndex) => matrix.map(row => row[colIndex]));
Q2: Are functional loops (.forEach) faster than standard loops for matrices?
No. When dealing with massive matrices (e.g., WebGL data, Canvas APIs), standard for(let i=0;...) loops are faster because they avoid the overhead of function context creation and callbacks on millions of data points.
